# Relatório de Vendas com Power BI

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar análise e visualização de dados utilizando Power BI.

O dashboard apresenta indicadores de vendas, lucro e unidades vendidas, permitindo a análise de desempenho por:
- Produto
- País
- Segmento
- Ano e trimestre

O foco do projeto foi desenvolver habilidades em:
- Construção de dashboards
- Storytelling com dados
- Visualização de informações
- Organização de métricas para tomada de decisão

---

## Ferramentas utilizadas

- Power BI
- Excel
- Modelagem de dados
- Visualização de dados

---

## Análises realizadas

### Relatório de vendas por produto
Análise das vendas por produto ao longo dos períodos disponíveis, incluindo:
- Distribuição de vendas
- Comparação entre produtos
- Filtro por ano e trimestre
- Comparação entre segmentos

### Distribuição por país
Visualização do desempenho de vendas entre diferentes países, com:
- Indicadores gerais
- Comparação entre regiões
- Evolução de lucro ao longo do tempo

### Distribuição de lucro, vendas e unidades vendidas
Análise geográfica e segmentada dos resultados:
- Lucro por segmento
- Vendas por país
- Quantidade de unidades vendidas
- Visualização em mapas

---

## Principais aprendizados

Durante o desenvolvimento deste projeto, pratiquei:
- Criação de dashboards interativos
- Organização visual de informações
- Uso de filtros e segmentações
- Escolha de gráficos adequados para análise
- Estruturação de indicadores de negócio
